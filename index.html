What this project does

AI training pipelines and digital logic circuits don't speak the same language — one works in floats and strings, the other works in bits. The AI Dataset Binary Encoder sits between them: it takes raw dataset columns (numeric or categorical), applies a chosen encoding scheme, and produces a clean binary dataset ready for digital-system processing, along with validation on every row.

    Validation checklist

    • Missing values — flagged or filled per your configuration.
    • Invalid input format — non-numeric text where a number was expected.
    • Incorrect binary length — value needs more bits than the selected bit length allows.
    • Duplicate encoding — two different categories mapped to the same binary code.
    • Negative numbers — unsigned binary can't represent them directly.

    About this project

    Problem

    AI datasets mix numeric and categorical values in formats digital systems can't process directly. Before a digital circuit or logic-level system can operate on data, that data needs a consistent binary representation — and someone has to define exactly how each value type maps to bits.

    Solution

    The AI Dataset Binary Encoder takes any CSV dataset, lets you pick an encoding scheme per field, and produces a validated binary dataset — with every conversion step shown, not hidden behind a black box.

    Benefits

    • Easy preprocessing — no spreadsheet macros or external scripts needed.
    • Standardized binary representation across numeric and categorical fields.
    • Explicit missing-value handling instead of silent data loss.
    • Built-in validation catches bad encodings before export.
    • One-click export to CSV or JSON for downstream digital-system tools.

    Course context

    Built for EC2201 — Digital Systems. The project applies number-system conversion (decimal → binary), encoding theory (label and one-hot encoding), and basic digital-logic concepts (bits, gates, encoder blocks) to a practical AI-data-preprocessing scenario.
